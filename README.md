# Anime Girlfriend Simulator

A lightweight Android starter app that simulates a cute anime companion with a stylized pseudo-3D character, mood states, affection tracking, and dialogue.

## Features
- 3D-inspired anime character drawn with Compose Canvas
- Multiple moods: idle, happy, blush, wave, and talk
- Affection meter and dialogue updates
- Simple mobile-friendly layout

## Requirements
- Android Studio Narwhal or newer
- JDK 17
- Android SDK 35

## How to run
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the `app` configuration on an emulator or a connected device.

## Notes
This is a stylized prototype rather than a full production 3D game engine setup. It provides a strong foundation for further expansion with custom character models, sound, and interaction systems.
